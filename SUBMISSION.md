# Материалы для организаторов

**Проект:** Гена — русскоязычный ассистент для задач, встреч, напоминаний и совместного планирования.
**Прототип:** https://meinangelplatz.top
**Исходники:** https://github.com/NIDJEL/assistant-ai
**Состояние документации:** 26 октября 2026 года.

## С чего начать

1. [README](README.md) — возможности, запуск одной командой, скриншоты и ограничения.
2. [Быстрый запуск](docs/QUICKSTART.md) — локальная проверка без ключей и полный режим.
3. [Архитектура](docs/ARCHITECTURE.md) — блоки, UML, данные и развёртывание.
4. [Проверка готовности](docs/ASSIGNMENT_VALIDATION.md) — воспроизводимые команды и границы проверки.

Для локальной проверки после клонирования: `python scripts/service.py up` (Linux: `./scripts/up.sh`). Для проверки свободной речи проще открыть HTTPS-прототип или настроить полный режим с собственными ключами. Создайте свой аккаунт; общий пароль демонстрационной учётной записи не нужен.

## Сценарий демонстрации

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Регистрация и onboarding | Явные согласия, новый пустой аккаунт, выбор темы. |
| 2 | Создать задачу с дедлайном | Запись появляется в задачах и календаре; подзадачи и приоритет редактируются. |
| 3 | Создать встречу, затем пересекающуюся | Конфликт показан до сохранения; без явного подтверждения нет неожиданного переноса. |
| 4 | Создать напоминание | Дата, время и упреждение видны в карточке; повторы задаются в редакторе. |
| 5 | Нажать «+» в чате | Три команды вставляют редактируемые шаблоны; отправка остаётся ручной. |
| 6 | Найти несколько записей и выбрать «вторую» | Выбор относится к текущему списку пользователя; неоднозначность уточняется. |
| 7 | Удалить запись и отменить подтверждение | До подтверждения запись сохраняется; удалённое можно восстановить из архива. |
| 8 | Импортировать `data/voice_assistant_events_1000.csv` дважды | 1000 исторических примеров без дублей при повторе того же набора. |
| 9 | Перезапустить через `down`, затем `up --no-build` | Аккаунт, сессия, записи и настройки остаются в PostgreSQL. |
| 10 | Открыть второй аккаунт | Первый аккаунт не раскрывает ему свои дела и диалоги. |

Подробные формулировки и проверка CSV — [docs/ASSIGNMENT_REVIEW.md](docs/ASSIGNMENT_REVIEW.md).

## Полный AI/голосовой сценарий

Нажмите микрофон → произнесите просьбу → остановите запись → проверьте черновик → отправьте. Например: «Чтобы не забыть, завтра в десять позвонить Ивану». При создании встречи без времени Гена должен уточнить его; ответ «в три часа дня» продолжает исходную команду. Ответ озвучивается по отдельному нажатию.

GigaChat понимает фразу; Groq распознаёт аудио; Azure озвучивает ответ. Нужны отдельные действительные credentials, сеть и разрешение микрофона. Режим без ключей проверяет интерфейс/исполнитель и правила, но не качество свободной речи.

## Дополнительные возможности

- Друзья: два независимых аккаунта, обмен кодами, подтверждение заявки, приглашение и согласование переноса.
- Яндекс Календарь: отдельное OAuth-согласие и экспорт дел наружу. Ссылку на онлайн-встречу можно указать вручную.
- Мобильный интерфейс: настройки интеграции открываются с первого нажатия; меню «+» закрывается повторным нажатием/снаружи; доступна установленная PWA.
- Ошибки: [404](https://meinangelplatz.top/errors/404) и [503](https://meinangelplatz.top/errors/503) — примеры оформленных HTTP-страниц. Preview 503 не останавливает сервис.

## Архитектурные решения для обсуждения

| Решение | Зачем |
| --- | --- |
| Типизированный контракт модели | Модель не выполняет SQL и не выбирает произвольные DB IDs. |
| Проверки и транзакции в Go | Авторизация, даты, конфликты, идемпотентность и согласованность состояния. |
| Outbox для внешних API | Сетевые сбои не откатывают локально сохранённое дело; есть повторные попытки. |
| PostgreSQL как рабочее хранилище | Данные, сессии и очереди переживают рестарт и разделены по владельцу. |
| Один Go runtime + статический frontend | Компактное развёртывание; Node не нужен в работающем контейнере. |
| Проверенный архив в CI/CD | Приложение собирается один раз; перед выпуском проверяются backup и health. |

## Честные границы

Не заявляются независимая оценка точности на любой речи, гарантированная доставка push, офлайн-редактирование, email-восстановление пароля, повторяющиеся встречи или двусторонняя синхронизация Яндекса. Живой микрофон, OAuth-согласие и воспроизведение на конкретном телефоне проверяются человеком отдельно. [Актуальные ограничения](README.md#ограничения-которые-нужно-учитывать-при-оценке).

## Перед передачей ссылки

- Проверить прототип и репозиторий в отдельной сессии браузера.
- Передать ссылку на ветку `main`/нужный commit и успешный CI, а не локальные артефакты.
- Не передавать `.env`, пароли, OAuth refresh tokens, VAPID private key и дампы базы.
- Для полного локального режима передать организаторам инструкцию получения их собственных credentials; не публиковать рабочие секреты.
