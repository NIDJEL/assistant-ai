# Архитектура актуального приложения

![Go, React и PostgreSQL](diagrams/architecture.svg)

Браузер использует React/TypeScript; Go обслуживает собранный интерфейс и HTTP API. PostgreSQL хранит аккаунты, сессии, события, историю диалогов, настройки, OAuth state и очереди. Node.js нужен для сборки и тестов. Python не входит в приложение.

Авторизация: email/пароль или Яндекс ID, серверные сессии, CSRF и PKCE. Все пользовательские данные изолируются владельцем. [Аккаунты и импорт](ACCOUNTS.md).

Команды разбирает локальный NLU. Ассистент уточняет неоднозначные запросы; изменения и идемпотентный ответ сохраняются транзакционно. Необязательный Ollama вызывается до write transaction. [Команды и поведение](ASSISTANT_BEHAVIOR.md), [русский NLU](RUSSIAN_NLU.md).

Диктовка остаётся редактируемым черновиком до ручной отправки:

![Голос и ручная отправка](diagrams/voice-flow.svg)

События содержат время, приоритет, детали, структурные повторения и параметры напоминаний. Удаление обратимо через архив. Импорт SQLite — отдельная команда; SQLite также используется для регрессионных тестов, рабочий сервер требует PostgreSQL.

Встроенный reminder worker под пользовательским advisory lock сохраняет occurrence, доставки и следующую дату повторения одной транзакцией. Sender использует SKIP LOCKED и ограниченные повторные попытки Web Push. Разовое напоминание после постановки уведомления в очередь завершается; задачи и встречи остаются открытыми. [Web Push/PWA](WEB_PUSH.md).

Изменения для Яндекс Календаря попадают в outbox одной транзакцией с событием. Отдельный worker выполняет CalDAV-запросы и повторы вне транзакции. [Яндекс Календарь](YANDEX_CALENDAR.md).

На VPS Nginx завершает HTTPS и проксирует на Go/React-контейнер. PostgreSQL не публикует порт; данные живут в постоянном томе. [Развёртывание и backup](../deploy/README.md). OpenAPI доступна по `/docs`, схемы — по `/architecture`.
