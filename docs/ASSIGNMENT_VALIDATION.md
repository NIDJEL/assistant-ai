Go-проверка выполнена на отдельной копии исходников: посторонние локальные эксперименты и secrets в сборку не включались. Обычные автоматические тесты используют fixtures/rules, а не платные live-запросы.

## Воспроизвести минимальную проверку

```bash
python scripts/service.py up
python scripts/service.py check
python scripts/smoke_auth.py --base http://localhost:8081 --phase prepare
python scripts/service.py down
python scripts/service.py up --no-build
python scripts/smoke_auth.py --base http://localhost:8081 --phase verify
```

Команды smoke создают синтетический аккаунт и записи: выполняйте их на своей тестовой установке. Временная cookie хранится в игнорируемом `tmp/p12-smoke.json` и удаляется после успешного verify; этот файл нельзя передавать. Если 8081 занят, задайте новый env, project и port согласно [QUICKSTART](QUICKSTART.md); используйте их во всех последующих командах.

Полный CI добавляет Chromium-сценарии CRUD/конфликтов, паролей, мобильных настроек, меню и страниц ошибок, а для выпуска — runtime-image smoke. Успех актуального коммита смотрите в [Actions](https://github.com/NIDJEL/assistant-ai/actions), а не по историческому числу тестов.

## Что требует отдельного окружения

- Полный GigaChat: действительные credentials/CA, доступная сеть и явный live-запуск. Новый live-бенчмарк произвольной речи в этой подготовке не заявляется.
- Физический микрофон, распознавание в шуме, воспроизведение на конкретном телефоне и Web Push проверяются на устройстве с разрешениями.
- OAuth-согласие Яндекса/Google/Zoom требует зарегистрированных приложений и аккаунтов пользователя; скриншоты не изображают фиктивные подключения.
- Доступ организаторов к приватному репозиторию и внешнему прототипу проверяется из отдельной сессии. Ключи, `.env` и дампы в передаваемый комплект не входят.
