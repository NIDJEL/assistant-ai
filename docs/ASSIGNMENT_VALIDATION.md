# Проверка доработок тестового — 20 октября 2026

Изменения проверены локально поверх `81d0f852455b8de16d681c9864e0f86faa0b524c`. На момент этой проверки выкладка на рабочий сайт, изменение видимости репозитория и выдача доступа не выполнялись. Состояние последующего выпуска следует проверять по Git SHA сервера и GitHub Actions.

## Что исправлено

- Встреча с человеком вне друзей сохраняется лично, с именами участников, временем, длительностью и настройкой напоминания. Ответ явно сообщает, что приглашения не отправлены.
- Обычные встречи с друзьями продолжают использовать существующее совместное планирование. Явное приглашение требует друга; явный отказ от приглашения сохраняет личную запись даже для друга.
- Неоднозначные имена, неоднозначные теги и ошибки хранилища не превращаются в автоматическое личное создание. Смешанный список известных и неизвестных участников не отправляет частичные приглашения. Отзыв дружбы не переводит существующий совместный подбор в личную встречу.
- Личное создание сохраняет выбранный режим после уточнения и перезапуска. Позднее добавление человека в друзья не отправляет приглашение автоматически.
- Уточнено понимание разговорных запросов, создания с отрицательной альтернативой, поиска истории без выдуманного периода и конца календарных периодов. Последнюю дату недели/месяца/года вычисляет Go через `period_end`.
- Добавлены связанные поисковые формулировки для презентаций, договоров, звонков, бюджета и дизайна. Приближённые результаты поиска не считаются точным выбором записи для изменения или удаления.
- В настройках появилась загрузка 1000 примеров истории. Повторный импорт не создаёт дубли; импорт ограничен текущим аккаунтом. Исправлена проверка доступности записи голоса в браузере.
- В README добавлены ссылка на прототип, отличие запуска с правилами от полного режима и описание решений. [Руководство для проверки](ASSIGNMENT_REVIEW.md) содержит сценарии и инструкции.

Живой прогон выполнен через настоящий `simple_llm`, реальные ответы GigaChat и выполнение операций в отдельных временных PostgreSQL-схемах. Проверены даты, время, типы записей, содержание, длительность упреждения, режим приглашений и количество сохранённых записей. Четыре поисковых сценария используют полный CSV из 1000 записей. Финальный machine-readable журнал сохранён локально в `artifacts/assignment-live-final.jsonl`; каталог `artifacts` исключён из Git.

Промежуточные прогоны выявляли ошибки модели, неверные ожидания тестового счётчика и отдельный сетевой сбой. Они использовались для исправлений. Финальные 25 сценариев — небольшой регрессионный корпус, не независимая оценка точности на произвольной речи и не вероятность выхода в финал.

Браузерный прогон проверяет интерфейс и режим правил. Два отключённых по умолчанию сценария требуют внешнего окружения: живое совместное планирование и Azure playback. Отдельная живая PostgreSQL-проверка покрывает новые LLM-сценарии; она не заменяет проверку браузерной карточки совместного планирования с настоящим провайдером. Физический микрофон, распознавание в шуме и качество воспроизведения на конкретном устройстве в этом прогоне не проверялись.
