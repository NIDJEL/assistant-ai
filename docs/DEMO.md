# Демонстрация за 5 минут

1. Запустить приложение по README. Открыть `http://localhost:8000` в Chrome/Edge. Для сценария с голосом заранее разрешить микрофон.
2. «Напомни мне завтра в 10 утра позвонить Ивану». Открыть вкладку «Завтра»: запись появилась. Включить озвучивание и повторить следующий запрос.
3. «В пятницу нужно отправить отчёт». Задача создаётся без времени; дата — ближайшая пятница.
4. «Поставь встречу с Иваном завтра». Получить вопрос о времени. Ответить «В 15:00». Если пример из CSV занял это время, выбрать другое или подтвердить пересечение.
5. «А перенеси её на послезавтра». Проверить новую дату и сохранение времени.
6. «Что запланировано на эту неделю?» Затем «Есть ли у меня встречи завтра?» — общий и типовой фильтр.
7. «Найди задачу про презентацию». Затем «Я когда-то ставил задачу по договору, найди её» и «Когда у меня была встреча с Иваном?» — результаты по архиву, включая прошлые годы.
8. По номеру найденной задачи: «Отметь задачу #42 выполненной» (подставить реальный номер). Переключить фильтр статуса на «Выполнено».
9. «Удали задачу #42». Ответить «нет» и убедиться, что запись осталась. Затем повторить и ответить «да», если созданная тестовая запись больше не нужна.
10. Обновить страницу и перезапустить сервер: события и текущий диалог сохраняются. Нажать «Загрузить 1000 примеров»: повторный импорт пропускает уже загруженные строки.
11. Открыть «Как это работает» и показать три блок-схемы. По нажатию схема открывается как масштабируемый SVG.

Для демонстрации уведомлений создайте напоминание с временем в ближайшую минуту, нажмите «Включить напоминания в браузере», разрешите уведомления и оставьте вкладку видимой. Уведомления не доставляются при закрытой вкладке.

Если голос не распознаётся: проверить микрофон и разрешение сайта, доступность сети и поддерживаемый браузер; использовать текстовый ввод, который проходит тот же обработчик.
