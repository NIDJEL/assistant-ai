# Компоненты интерфейса и проверка UI

[Интерфейс](WORKSPACE_DESIGN.md) · [Свежая галерея](SCREENSHOTS.md)

Текущая UI-система включает:

- календарь месяц/неделя/день с отдельным списком выбранной даты;
- общий DatePicker и Select с клавиатурой, Escape и ограничением видимой областью;
- адаптивные Dialog/drawer, focus management и восстановление фокуса;
- авторазмер поля сообщения/заметки, ручную отправку диктовки;
- независимое раскрытие групп напоминаний, управление виджетами и сохранение настроек;
- тёмную/светлую тему и reduced motion;
- меню команд «+», мобильные настройки интеграций, оформленные ошибки.

Смысл UI-проверки — пройти действие и проверить результат: открыть панель с первого нажатия, вставить шаблон без отправки, сохранить изменения, повторить неудавшийся запрос, убедиться в отсутствии переполнения и ошибок страницы. Только снимок экрана не доказывает работу операции.

Основные сценарии находятся в `web/e2e/controls.spec.ts`, `ui-polish.spec.ts`, `themes.spec.ts`, `mobile-settings-commands-errors.spec.ts` и `flows.spec.ts`. CI запускает короткий обязательный набор; полный Chromium-набор доступен вручную. WebKit используется отдельно для проверки поведения, близкого к Safari. [Команды](DEVELOPMENT.md).

[Исторический отчёт UI](history/2026-10-ui-polish.md) сохраняет контекст прежних доработок, но его количества тестов и измерения не описывают новую версию.
