# OAuth provider marks

The original SVG artwork is stored locally and loaded through Vite so sign-in does not depend on external image requests.

- `yandex.svg`: rounded icon from the official [Yandex ID button design documentation](https://yandex.ru/dev/id/doc/ru/codes/buttons-design), downloaded 2026-10-13. Artwork and colors are unchanged.
- `vk.svg`: original [`logo_vk_color_56.svg`](https://github.com/VKCOM/icons/blob/master/packages/icons/src/svg/56/logo_vk_color_56.svg) from VK's official icon library, downloaded 2026-10-13. Artwork and colors are unchanged. The display size compensates for the SVG's built-in empty margin; the mark keeps its original proportions.

VK's library license is included in `VK-LICENSE.txt`.
