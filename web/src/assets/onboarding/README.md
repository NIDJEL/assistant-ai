# Onboarding artwork

These ten WebP assets are derived from the user's supplied transparent PNGs dated 2026-10-22 (03:37:17 through 03:37:24). Only transparent margins, size and encoding were optimized. The mascot, mark, checklist, board, notification, service icons, sparkle and button retain the supplied artwork. The three complete card screenshots guide the compositions; they are not flattened screenshots used as UI.

The UI uses real HTML text and buttons over separate decorative images. The combined asset size is approximately 307 KB, with only the current scene's images requested. CSS animation uses transforms and opacity; pointer parallax runs only for a fine pointer, stops when settled and resets in a hidden tab. Both the OS reduced-motion preference and the app's reduced-motion setting disable decorative movement.
